# Código de conducta

Este proyecto lo hacen aficionados en su tiempo libre, y participa gente de edades, países y niveles muy distintos.
Las normas son las mismas que en [foro.pcfsite.com](https://foro.pcfsite.com/normas), resumidas:

- **Respeto.** Se discuten ideas y código, no personas. Sin insultos, burlas, acoso ni comentarios sobre el origen,
  el género, la orientación, la religión o cualquier otra condición de nadie.
- **Buena fe.** Quien abre un issue o una pull request está intentando ayudar. Si algo está mal, se explica por qué
  y cómo se arregla, no se ridiculiza.
- **Sin ficheros de los juegos.** No se suben ni se enlazan CD, ISO, ejecutables, datos ni el código C generado a
  partir de ellos: ni en issues, ni en pull requests, ni en el foro. Los registros (`.log`) y las capturas de
  pantalla sí valen.
- **Sin spam ni autopromoción** fuera de lo relacionado con el proyecto.

Esto se aplica en el repositorio (issues, pull requests, discusiones), en el hilo del foro y en cualquier canal del
proyecto.

**Si alguien se pasa**, escribe a jordiruiz@nuvola.cat o a un moderador del foro. Se lee todo y se responde en
privado. Según el caso se avisa, se borra el contenido o se expulsa a la persona del repositorio y del foro.
